# Portafolio de Excel y Power BI

## Inicio

Instala las dependencias y ejecuta el proyecto:

```powershell
npm install
npm run dev
```

Luego abre `http://localhost:3000` en tu navegador.

## Dónde editar

- `public/index.html`: textos, proyectos y enlaces.
- `public/css/styles.css`: apariencia de la web.
- `public/images/`: capturas o imágenes de tus proyectos.
- `public/js/main.js`: comportamiento sencillo de la página.
